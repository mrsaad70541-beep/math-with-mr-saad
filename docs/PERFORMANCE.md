# قياس الأداء (Lighthouse)

التاريخ: 2026-11-27. الهدف: الصفحة الرئيسية للإصدار المنشور على GitHub Pages.

## الطريقة
- الأداة: Lighthouse 12.8.2، وضع الجوال الافتراضي (تقييد محاكى للمعالج والشبكة)، فئة الأداء فقط.
- الرابط المقيس: `https://mrsaad70541-beep.github.io/math-with-mr-saad/` (الإنتاج، ليس نسخة محلية).
- زمن التفاعل قِيس أيضًا بنقرات حقيقية على الإنتاج بعرض 390px (متصفح بلا تقييد)، لأن INP مقياس ميداني لا يظهر في فحص مخبري.

- INP لا يُقاس مخبريًا؛ بدائله المخبرية (TBT = 0 وMax Potential FID = 20 م.ث) ضمن الحد الجيد. القياس الميداني الحقيقي يحتاج بيانات مستخدمين فعليين.

## عوامل مساعدة
- التطبيق ملفات ثابتة بلا خطوة بناء، و`sw.js` يخزّنها بعد أول زيارة فتصبح الزيارات التالية شبه فورية.
- لا مكتبات طرف ثالث ثقيلة؛ الخط من Google Fonts مع روابط preconnect.

## حدود هذا القياس
- قياس مخبري على الصفحة الرئيسية فقط في هذا التاريخ؛ صفحات أخرى وأجهزة حقيقية وشبكات ضعيفة قد تختلف.
- لا يمثّل ادعاءً بأداء عدد كبير من المستخدمين المتزامنين؛ الاستضافة ثابتة على GitHub Pages ولا خادم تطبيق يُقاس تحميله هنا.
